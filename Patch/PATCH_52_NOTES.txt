MiniCut - Patch 52 (Effect editor rework)         [โค้ดรวมอยู่ในโปรเจกต์นี้แล้ว]
================================================================

แก้อะไร
- node ในหน้า Effect editor ต่อสายไม่ได้ -> เขียนระบบต่อสายใหม่ให้ทำงานเหมือน node editor หลักทุกอย่าง
  (socket จัดการ กด/ลาก/ปล่อย เอง) ต่อ node ผิดชนิดหรือต่อวนจะถูกปฏิเสธพร้อมข้อความ
- หน้าตาใหม่: การ์ด/ผืนผ้าใบจุด/สาย แบบเดียวกับ node editor หลัก ตามธีมมืดของโปรแกรม แต่ใช้ชุดสี node คนละชุด
- Effect ที่สร้างจาก editor เดิมแทบไม่ทำงานเลย (20 จาก 23 node พัง) -> เขียนตัวคอมไพล์ใหม่ (Patch 50/51 รวมอยู่แล้ว)

ฟีเจอร์ใหม่
- Undo/Redo, Copy/Paste (ข้ามเอฟเฟกต์ได้), Cut, Duplicate, Mute, Arrange, ลากกรอบเลือก, Fit, เมนูคลิกขวา
- ค้นหา node: กด Tab บนผืนผ้าใบ (หรือดับเบิลคลิกที่ว่าง) หรือช่องค้นหาด้านซ้าย (พิมพ์ไทย/อังกฤษได้)
- ทุกพารามิเตอร์ที่เป็นตัวเลข/สี อยู่บนการ์ดและมีช่องต่อสาย: ต่อ Time / Wave (LFO) / Map Range /
  Parameter / Constant / Math เข้าไปให้ค่าวิ่งตามได้
- ปุ่มกุญแจ (key) ข้างพารามิเตอร์ = ส่งเป็นสไลเดอร์ของเอฟเฟกต์ใน inspector (ใส่คีย์เฟรมได้) เปลี่ยนชื่อสไลเดอร์ได้ในแผง Sliders
- node ใหม่: Solid Color, Gradient, Checkerboard (สร้างภาพ), Wave (LFO), Map Range (สร้างค่า)
- พรีวิวสด: ใช้รูปเดียว (จากมีเดียในโปรเจกต์ / ไฟล์ / รูปทดสอบ) เล่นวน 3 วินาที
  ปรับความละเอียดตามความเร็วของเอฟเฟกต์ เอฟเฟกต์ที่ไม่ขยับจะวาดครั้งเดียวแล้วหยุด (ไม่กินเครื่อง)

ปุ่มลัด (ใน editor)
  Tab ค้นหา node | Del ลบ | Ctrl+C/V/X/D คัดลอก/วาง/ตัด/ทำซ้ำ | M mute | Ctrl+Z / Ctrl+Y undo/redo
  F fit | Ctrl+S บันทึก | Space เล่น/หยุดพรีวิว | คลิกกลางลาก = เลื่อนมุมมอง | ล้อเมาส์ = ซูม

เรื่องระบบ patch
- apply_52 เก็บ backup ที่ <โฟลเดอร์ Launcher>/_patch_backup (ที่ที่ Launcher หา) จึงใช้ "Undo Last Update" ได้
  และหา root ของโปรแกรมเองไม่ว่าจะรันผ่าน Launcher หรือรันตรงจากโฟลเดอร์ Patch
- (apply_50/51 เดิมเขียน backup ไว้ที่ minicut/_patch_backup ซึ่ง Launcher มองไม่เห็นในโครงสร้างโฟลเดอร์ใหม่)
